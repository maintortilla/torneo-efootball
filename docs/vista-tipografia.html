Tipografías para la web

La que usa LaLiga Fantasy es “LALIGA Text”, una fuente de encargo de LaLiga (no es libre, no se puede usar). Aquí tienes alternativas gratis con aire parecido (geométricas, modernas, deportivas), aplicadas a cosas reales de tu web para que las compares. Arriba del todo está la que usas ahora, para que veas la diferencia.

Dime el número o el nombre de la que más te guste y la aplico a toda la web. Si te gusta una pero con los números de otra, también se puede mezclar.
