Tipografías para la web

La que usa LaLiga Fantasy es “LALIGA Text”, una fuente de encargo de LaLiga (no es libre, no se puede usar). Aquí tienes alternativas gratis aplicadas a cosas reales de tu web, con una etiqueta que dice a qué parte pertenece cada cosa.

títulos números etiquetas texto botones

Dime número + rol, por ejemplo: 4 para títulos, 2 para números, 7 para texto… y así con los que quieras. Se pueden mezclar todos los que quieras. El 1 es la que usas ahora, para que compares.
